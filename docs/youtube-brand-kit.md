## Upload notes

YouTube's recommended banner size is 2560 × 1440, with important text and logos kept inside the responsive safe area. This pack uses a 2048 × 1152 version with the identity deliberately centered; if YouTube requests a larger file, export the same composition at 2560 × 1440 without moving the center lockup.
