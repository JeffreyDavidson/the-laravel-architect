# Project description template

Use this template for every new project in the Filament project editor. Keep the short description concise and use the full write-up to explain the problem, the work, and the result.

## Short description

Write one or two sentences that identify:

- What the project is
- Who it serves
- The primary problem or capability it addresses

Prefer a clear, factual sentence beginning with “A…” or “An…”. Avoid a technology-only list, unsupported metrics, and vague claims.

Example:

> A multi-tenant SaaS platform that helps home bakers manage storefronts, orders, payments, customers, finances, and day-to-day operations.

## Full write-up

Copy this Markdown structure into the content field:

```markdown
## The problem

Describe the audience, situation, or limitation that made the project necessary. Explain the real-world problem before discussing features or technology.

## The solution

Explain what was built, your contribution, and the design or architecture decisions that shaped the result.

## Highlights

- List three to six meaningful capabilities or decisions
- Describe outcomes and user value, not just package names
- Include technology only when it helps explain the implementation

## The result

Describe the verified outcome, current status, or what the project demonstrates. Say clearly when the project is still in development.
```

## Editorial checklist

- Store the write-up as Markdown, never raw HTML.
- Use the headings exactly as shown unless the project genuinely needs a different structure.
- Write in a confident, direct portfolio voice.
- Explain the problem before listing features.
- Describe Jeffrey’s specific contribution where relevant.
- Keep the length comparable to the other project write-ups.
- Use three to six highlights instead of an exhaustive feature dump.
- State development status honestly.
- Use only verified outcomes, metrics, roles, quotes, and client claims.
- Add screenshots with short captions when they clarify the work.
- Keep the short description and full write-up complementary rather than repetitive.
